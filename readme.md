项目核心框架介绍 : python + selenium + PO + pytest + allure + jenkins
1.提供基础框架封装（面向对象）：base层，主要是元素定位、页面操作方法封装 
    - 封装公共方法：元素定位、打开浏览器、输入、点击、切换窗口、切换frame、截图等
2.提供页面对象封装（PO）：pages层，页面对象封装，主要封装页面操作方法
    - 封装每个页面对象：元素定位（属性）、页面操作（方法）
3.提供页面脚本层（pytest）：scripts层，主要封装测试的页面业务脚本
    - 封装测试脚本：测试用例（准备数据、调用测试方法、打印结果、断言）
4.其他层：
    - data测试数据层
    - report测试报告层
    - log日志层
    - img截图层
    - config.py是项目配置信息
    - pytest.ini是pytest配置文件
5.tools工具层：封装浏览器驱动、操作日志记录、读取JSON文件
